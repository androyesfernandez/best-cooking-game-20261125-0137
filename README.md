RUSH HOUR KITCHEN — a 7-day arcade line-cook game: grab ingredients from 8 crates, cook them at 5 named stations, build 12 recipes on 2 plates, and serve 12 named regulars before their patience runs out. Combos to x5, 9 upgrades in the between-day shop, synth WebAudio.

## Play

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `game/index.html` directly in a desktop browser (plain static files, no network requests).
